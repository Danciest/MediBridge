# MediBridge — Starter MVP
Sample text
A front-end starter for the MediBridge college project.

## Current features

- Public landing page
- Login/register demo
- Donor dashboard
- NGO dashboard
- Admin dashboard
- Add medicine
- Medicine inventory
- NGO medicine requests
- Admin request approval/rejection
- Reward points UI
- Profile UI
- Responsive design
- Role switcher for demo/testing
- Local browser state for selected role

## Run

No build system is required for this starter.

1. Open `index.html` in a browser, or use VS Code Live Server.
2. Click Register/Login.
3. Use the role switcher in the dashboard to test Donor, NGO and Admin flows.
